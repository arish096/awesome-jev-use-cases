# Contributing

Open a pull request that adds one entry.

Rules for an entry:

1. Link to proof made by the builder, such as source code, a live demo, or a post that shows the thing running.
2. Say what Jev does in the system, and which question types it uses if the builder said.
3. Give numbers as reported and name who reported them. If you measured something yourself, say how.
4. Put anything unbuilt in the ideas section and mark it as an idea.
5. Keep each entry to one to three sentences.
6. Use this format: `- [Name](link) by @author. Description.`
7. Open every link before you submit, and make sure it loads.

Entries that describe a limit or a failure are as welcome as entries that describe a success. TypeSafe's [jaggedness page](https://docs.typesafe.ai/model-jaggedness/jev-1.13) lists known limits, and it asks for new ones on its Discord.
